UI revamp · vision v1 · October 2026

LexReg, redesigned — every screen on one calm system.

From the home page through sign-in, both onboarding paths and the dashboards to the admin console. Built from the Zeno admin console’s tokens, LexReg’s burgundy on white, and Apple’s Human Interface Guidelines for hierarchy, materials and motion.

Start the walkthrough See the design system Jump to the dashboard

Zeno admin tokens

Apple-web neutrals, 0.5px hairlines, 12px cards with a soft two-layer shadow, a translucent sidebar with uppercase group labels, dense type and large tabular numerals.

LexReg colour

Burgundy #800020 on white stays the brand. It marks the one primary action, the current place and the entity itself — an accent, never a wash.

Apple HIG

System type with size-specific tracking, glass only on navigation, critically damped springs that respond on press, 44pt touch targets, and reduced-motion and reduced-transparency fallbacks.

How to review. Press Play on any board to click through — links move between screens, so whole flows can be walked end to end. Every board has a Dark appearance tweak, and boards with states (uploading, reading, errors) have a state tweak. Phone boards show the same screens at 390 points wide.
