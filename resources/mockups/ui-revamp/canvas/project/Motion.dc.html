04

Rules

Every animation in LexReg passes all eight.

Respond on press

Feedback starts on pointer-down within 110ms. The action commits on release.

Never block input during transitions

No control is disabled while something moves. A tap mid-animation retargets it.

Animate from the current value

Interrupted motion continues from where it is. It never snaps back to the start.

Enter and exit on the same path

A sheet leaves the way it came. Forward steps enter from the right, back from the left.

Origin at the trigger

Sheets, popovers and menus grow from the control that opened them, set with --origin.

Reduced motion becomes cross-fades

With Reduce Motion on, entrances, steps, sheets and toasts become a 200ms fade. Nothing slides or scales.

Reduced transparency becomes solid

Glass turns into the surface colour; the toast turns solid ink.

No infinite loops except real progress

Only the OCR scan and loading shimmer repeat, and only while work is happening.
