LexReg design system v2

The tokens, type, materials and rules every LexReg screen is built from. Calm Apple-style neutrals from the Zeno console, LexReg burgundy as the only accent, and one idea that runs through everything: every value shows the evidence behind it.

Foundations Components Motion

01

Principles

Six rules that decide every screen. When two conflict, the earlier one wins.

Evidence before entry

Every pre-filled value shows which document it came from. Two documents agreeing is verified; one is extracted; a disagreement is a conflict the owner resolves.

One primary action

Each view has one burgundy button: the next thing to do. Everything else is tinted, gray or plain, so the path forward is never in doubt.

Drafts never lost

Every onboarding step saves to the entity draft as you go. Save & exit is always one click away and you return to the exact field you left.

Calm by default

Neutrals carry the interface. Burgundy is an accent: it marks where you are and what to do next, never decoration or large washes.

Respond on press

Controls react on pointer-down within 110ms. Transitions never block input; a new tap interrupts and redirects from the current value.

Plain legal language

Say “Upload CR12” and “Confirm 3 directors”, not “Submit documents”. Cite the Companies Act 2015 in one sentence only when it changes what the owner does.
